01 / FOUNDATIONAUI

A shared architecture.
A practical foundation.

AUI means Absolute Universal Intelligence. It is the name of Valkrai’s authored architecture: a framework of responsibilities for creation, execution, direction, governance and adaptation.

These responsibilities give the work a common vocabulary. Each implementation must still establish its own behavior, boundaries and evidence.

AUI guides implementation and review. Current public software is described below, alongside the work still proposed.
